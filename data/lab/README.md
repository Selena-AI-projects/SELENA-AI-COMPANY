# Материалы Selena Lab файлами

Один файл — одна языковая версия одного материала: `<раздел>/<slug>.<en|ru>.json`.
Раздел — `articles`, `guides` или `experiments`. Формат и правила — в
`docs/22-selena-lab-publishing.md`.

Такие файлы приносит pull request из Control Room после одобрения материала.
Слить его — значит опубликовать: сайт выкладывается из `main`. Руками файлы не
правят — изменение, сделанное после одобрения, расходится с одобренным текстом.

Файл со сбоем не пропускается, а останавливает сборку. Иначе сайт молча вышел
бы без статьи, которую владелец слил.

`english-only.json` — адреса английских материалов, у которых ещё нет русской
версии. Pull request с новой английской статьёй добавляет сюда её адрес, а
pull request с русской версией его убирает.
