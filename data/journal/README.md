# Детали замеров

Один файл — один замер одного проекта: `<slug>/<дата>.json`.

Файлы пишет прогон замера на Railway и открывает pull request. Руками их не
редактируют: число, набранное человеком, рано или поздно разойдётся с тем, что
на самом деле ответила машина, и никто этого не заметит.

Пустая папка — это не «ничего не нашли», а «ещё не спрашивали». Пока файла нет,
на странице проекта таблицы просто не будет.
