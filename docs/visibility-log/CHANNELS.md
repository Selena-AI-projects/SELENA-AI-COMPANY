# Два канала: что продаётся за $49 и за $79

## Чем каналы отличаются

**Visitor View** — ответ, который видит живой человек в ChatGPT, Gemini или
Perplexity. Эти сервисы отвечают с веб-поиском, поэтому результат зависит от
того, что они находят в интернете прямо сейчас.

**API View** — та же модель, опрошенная напрямую через API, без поиска. Это
проверка того, что модель знает о бренде из собственного обучения.

Продать один канал под видом другого — главная ошибка, которую в этом продукте
специально нельзя совершить: у permit есть канал, и адаптер принимает только
свой.

## Что входит в тарифы

| | $49 Visitor Local | $79 Full AI Landscape |
| --- | --- | --- |
| Visitor View | да, 3 сервиса | да, 3 сервиса |
| API View | нет | да, 5 моделей |
| Систем всего | 3 | 8 |
| Языков | 1 | 2 |
| Ответов в месяц | 300 | 800 |

$79 — это **не другой** способ замера, а $49 плюс API View. Надстройка, а не
альтернатива.

## Что из этого работает сегодня (25 августа 2026)

| Канал | Провайдер | Состояние |
| --- | --- | --- |
| API View | OpenRouter | **Работает.** Замер KORA проведён, стоил $0.23 |
| Visitor View | Bright Data | **Не подключён.** Адаптер написан и покрыт тестами, но нигде не зарегистрирован |

Практический вывод, неприятный, но важный: **тариф $49 сегодня продать нельзя** —
он целиком состоит из канала, который не подключён. У тарифа $79 работает только
вторая половина.

## Что нужно, чтобы включить $49

Порядок из `SELENA_VISITOR_VIEW_BRIGHTDATA_WIRING.md` в репозитории приложения.
Те же пять шагов, что мы прошли с OpenRouter, только провайдер другой.

**Со стороны владельца — два шага:**

1. Аккаунт Bright Data и жёсткий лимит расходов на нём, по зонам. Как и с
   OpenRouter, это единственное ограничение, которое удержит, если приложение
   поведёт себя неверно.
2. Три значения в окружении воркера на Railway:
   `BRIGHTDATA_API_TOKEN`, `SELENA_BRIGHTDATA_ENDPOINT` (обязательно HTTPS —
   адаптер отказывается от plaintext, потому что токен идёт в заголовке) и
   `SELENA_BRIGHTDATA_ZONE`.

**Со стороны помощника — три шага:** передать адаптеру чтение текста сценария,
зарегистрировать по одному экземпляру на каждый из трёх сервисов (ChatGPT,
Gemini, Perplexity — один экземпляр меряет одну поверхность), и внести
`brightdata` в список адаптеров, одобренных владельцем.

### Сходится ли экономика

В каталоге у тарифа `visitor-local` заложен `providerBudgetCap: 12` — двенадцать
долларов на провайдера в месяц при выручке $49 и 300 ответах. Это $0.04 на
ответ. Настоящую цену Bright Data проверить отсюда нельзя: их сайт закрыт той же
сетевой политикой. Первый счёт и покажет, сходится ли, — ровно так же, как
$0.0017 у OpenRouter оказались втрое ниже нашей модели.

## Третий путь, который стоит знать

Между двумя каналами есть промежуток: модель, опрошенная через API **с
включённым веб-поиском**. У OpenRouter такая возможность есть, и в адаптере
API View она отключена намеренно — в руководстве владельца это записано так:
«веб-поиск никогда не включается и плагин поиска не отправляется: API View — это
собственные знания модели, и каталог продаёт именно их».

Такой замер можно запустить сегодня, тем же ключом, без Bright Data. Но это
**не Visitor View**: человек на chatgpt.com видит интерфейс со своей выдачей, а
не ответ API с поисковым плагином. Продать одно под видом другого — ровно та
ошибка, от которой продукт защищён разделением каналов.

Если такой замер понадобится, он должен продаваться как отдельная вещь и
называться своим именем, а не заполнять дыру на месте $49.
