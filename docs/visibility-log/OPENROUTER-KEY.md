# Ключ OpenRouter: куда вставить

Инструкция для владельца. Приложение (воркер, который делает замеры) живёт в
репозитории `parkourcafe/selena-ai-visibility` и разворачивается на Railway.
Сайт `selenasystems.com` тут ни при чём — ключ ему не нужен.

## Шаг 1. Сначала лимит, потом ключ

Порядок важен: лимит на аккаунте — единственное ограничение, которое удержит,
даже если приложение поведёт себя неправильно.

1. OpenRouter → **Settings** → раздел кредитов и лимитов.
2. Поставить месячный лимит. Для первого замера по семи проектам с большим
   запасом хватит **$10**.

По нашей модели один ответ стоит около $0.005, то есть первый замер (25 вопросов
× 3 системы × 7 проектов = 525 ответов) должен обойтись примерно в $2.60. Эта
цифра **пока не проверена на живых данных** — именно поэтому лимит нужен до
ключа, а не после.

## Шаг 2. Создать ключ

OpenRouter → **Keys** → **Create Key**. Имя: `selena-worker`.

Если OpenRouter предложит лимит на сам ключ — поставить и его. Два ограничения
лучше одного.

## Шаг 3. Куда вставить

Railway → проект Selena → сервис **worker** → вкладка **Variables** →
**New Variable**. Три переменные:

| Имя | Значение |
| --- | --- |
| `OPENROUTER_API_KEY` | ключ из шага 2 |
| `SELENA_MEASUREMENT_ADAPTER` | `openrouter` |
| `SELENA_MEASUREMENT_ENABLED` | `true` |

Затем сервис **web** → **Variables** → одна переменная:

| Имя | Значение |
| --- | --- |
| `SELENA_MEASUREMENT_ENABLED` | `true` |

Модель задавать не нужно: по умолчанию берётся `anthropic/claude-haiku-4.5` из
каталога. Переменная `SELENA_OPENROUTER_MODEL` существует, но менять её стоит
только чтобы измерить другую модель из каталога — замер измеряет ту модель,
которую купил клиент.

После сохранения Railway передеплоит сервисы сам.

## Шаг 4. Кто нажимает «запустить»

Замер не стартует по таймеру — только явным действием из админки приложения.
Помощник не может нажать эту кнопку: сетевая политика его среды не пропускает
исходящие соединения ни к Railway, ни к app.selenasystems.com.

Если нужно, чтобы замер запускался кнопкой в GitHub Actions (как отчёт Search
Console), это делается — но тогда в секреты GitHub придётся положить адрес
production-базы. Отдельное решение, отдельный разговор.

## Чего не делать

Не присылать ключ в переписку с помощником. Ключ вводится только в Railway.
Всё, что нужно сообщить после настройки, — что переменные сохранены.
