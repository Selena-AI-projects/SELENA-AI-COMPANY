# Замер AI-ответов: что включить

Инструкция для владельца. Приложение, которое делает замеры, живёт в репозитории
`parkourcafe/selena-ai-visibility` и разворачивается на Railway. Сайт
`selenasystems.com` тут ни при чём.

## Новый ключ не нужен

`OPENROUTER_API_KEY` на воркере уже стоит, и адаптер замеров читает именно его —
ту же самую переменную, что и остальные части приложения:

- провайдерский реестр Elmo (`packages/lib/src/providers/registry/openrouter*.ts`);
- онбординг-LLM;
- адаптер замеров Selena.

Менять его не нужно. Осталось только включить два переключателя.

## Что включить

Railway → проект Selena → сервис **worker** → **Variables**:

| Имя | Значение |
| --- | --- |
| `SELENA_MEASUREMENT_ADAPTER` | `openrouter` |
| `SELENA_MEASUREMENT_ENABLED` | `true` |

Сервис **web** → **Variables**:

| Имя | Значение |
| --- | --- |
| `SELENA_MEASUREMENT_ENABLED` | `true` |

Модель задавать не нужно: по умолчанию берётся `anthropic/claude-haiku-4.5` из
каталога. `SELENA_OPENROUTER_MODEL` существует, но менять её стоит только чтобы
замерить другую модель из каталога — замер измеряет ту модель, которую купил
клиент.

После сохранения Railway передеплоит сервисы сам.

## Лимит расходов — обязательно, и до включения

Лимит на аккаунте OpenRouter — единственное ограничение, которое удержит, даже
если приложение поведёт себя неправильно. Поскольку ключ один на всё
приложение, лимит защищает не только замеры.

OpenRouter → **Settings** → кредиты и лимиты. Для первого замера по семи
проектам с запасом хватит **$10**.

По нашей модели один ответ стоит около $0.005, то есть первый замер (25 вопросов
× 3 системы × 7 проектов = 525 ответов) должен обойтись примерно в $2.60. Эта
цифра **пока не проверена на живых данных** — именно поэтому лимит нужен до
включения, а не после.

## Побочный эффект одного ключа

Расходы замеров и расходы остальных частей приложения смешиваются на одном
ключе. Счёт OpenRouter не покажет, сколько стоил именно замер, а настоящая
себестоимость ответа — открытый вопрос из `DECISIONS.md`.

Решается отдельным ключом: адаптер начинает читать `SELENA_OPENROUTER_API_KEY`,
а если её нет — падает обратно на `OPENROUTER_API_KEY`. Тогда у замеров свой
ключ, свой лимит и своя строка в счёте. Это правка в коде на несколько строк;
делать её или нет — решение владельца.

## Кто нажимает «запустить»

Замер не стартует по таймеру — только явным действием из админки приложения.
Помощник не может нажать эту кнопку: сетевая политика его среды не пропускает
исходящие соединения ни к Railway, ни к app.selenasystems.com.

Если нужно, чтобы замер запускался кнопкой в GitHub Actions (как отчёт Search
Console), это делается — но тогда в секреты GitHub придётся положить адрес
production-базы. Отдельное решение.

## Чего не делать

Не присылать ключ в переписку с помощником. Всё, что нужно сообщить после
настройки, — что переменные сохранены.
