# Открытый журнал видимости

Долгосрочная ветка работы: семь собственных проектов Selena Systems проходят
всю продуктовую лестницу публично, на живых данных.

Эта папка — память проекта. Она существует, чтобы работу можно было продолжить
из любого инструмента и после любого перерыва: достаточно прочитать три файла
по порядку.

| Файл | Что в нём |
| --- | --- |
| `PLAN.md` | Что делаем, в каком порядке и по каким правилам |
| `DECISIONS.md` | Принятые решения с датами — чтобы не переспорить их заново |
| `PROJECTS.md` | Семь проектов, их рынки и языки замера |
| `BASELINE-2026-08-25.md` | Предварительный исторический снимок; не использовать для сравнений |
| `BASELINE-2026-08-26.md` | Подтверждённый Search Console baseline для семи проектов |

После подключения ключа свежие данные Search Console будут собираться каждый понедельник
(`.github/workflows/gsc-report.yml`) в закрытый артефакт GitHub Actions.
Baseline от 26 августа собран исправленным отчётом и контрольным сравнением с
интерфейсом Search Console. Полные отчёты остаются закрытыми артефактами.

## Как продолжить работу

Прочитайте `DECISIONS.md` — там сказано, что уже решено и что ещё открыто.
Открытые вопросы отмечены как ОТКРЫТО и требуют решения владельца.
