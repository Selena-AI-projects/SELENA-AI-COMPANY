# Диагностика сетевого отказа — 11.10.2026, 21:15 Asia/Makassar (UTC+8)

Среда: контейнер сессии Claude Code. Node.js 22.22.0 по умолчанию (`/opt/node22`), также 24.21.0. `HTTPS_PROXY=http://127.0.0.1:<порт>` задан; `NO_PROXY` содержит только служебные адреса, реестр npm и PyPI. Проверка TLS не отключалась, политика не обходилась.

## Один адрес, три клиента

Адрес: `https://skift.com/feed/` (лента из `sources.json`).

| Клиент | Результат | Класс ошибки |
|---|---|---|
| `curl` через прокси сессии | `curl: (56) CONNECT tunnel failed, response 403`; в журнале прокси: `connect_rejected skift.com:443 — gateway answered 403 to CONNECT (policy denial)` | **отказ прокси / allowlist** |
| `curl --noproxy '*'` напрямую | `curl: (6) Could not resolve host: skift.com`; `getent hosts skift.com` пусто | **DNS: у контейнера нет прямого выхода, только через прокси** |
| Node `fetch` без флага (так шёл скрипт) | `getaddrinfo ENOTFOUND skift.com` | тот же DNS: `fetch` в Node не читает `HTTPS_PROXY` без флага |
| Node `fetch` с `--use-env-proxy` (22.22 и 24.21) | `fetch failed`, причина `Request was cancelled.` | тот же **отказ прокси**, что у curl, в другой формулировке |
| Node `fetch` с `--use-env-proxy`, разрешённый хост `app.selenasystems.com` | `200` | прокси работает; отказ зависит от хоста |

Вывод. Отказ — не DNS-сбой и не неверный адрес ленты, а сетевая политика окружения: шлюз отвечает 403 на CONNECT к любому хосту вне allowlist. Прежняя формулировка «ENOTFOUND» в отчёте объяснялась тем, что скрипт шёл мимо прокси; это исправлено в документации (`NODE_OPTIONS=--use-env-proxy` за прокси). HTTP-ошибки (404 на неверном адресе ленты, 5xx) из этой среды получить нельзя: до HTTP-уровня соединение не доходит. Правильность адресов лент с `feedGuess: true` поэтому не проверена и проверится только после открытия доступа.

Критик карты до этого отправил 38 одиночных запросов по тем же хостам через прокси — все отклонены на CONNECT.

## Действие в интерфейсе

В сессии Claude Code: меню облачного окружения в заголовке сессии → **Edit** → **Network access** → уровень **Limited** → **Allowed domains**: вставить список выше, оставить включённым «Allow package managers» → сохранить. Описание настройки: https://code.claude.com/docs/en/cloud-environments#network-access. После этого в контейнере запуск выполняется с `NODE_OPTIONS=--use-env-proxy`:

```bash
NODE_OPTIONS=--use-env-proxy node scripts/editorial/run.mjs --verify-sources --write --verified-where session-container
NODE_OPTIONS=--use-env-proxy npm run editorial:draft
```

На машине без прокси флаг не нужен.
