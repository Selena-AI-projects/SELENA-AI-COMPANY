# Редакционный запуск Selena Lab: от повода до черновика

Одна команда читает настроенные источники, отбирает один проверяемый повод про ИИ-поиск и рестораны или отели, подтверждает его дословными местами на странице первоисточника, пишет русскую статью, английскую адаптацию и анонс для Telegram через Claude Code и сохраняет пакет черновика. Ничего не публикует и никуда не отправляет.

```bash
npm run editorial:draft
```

## Что нужно на машине

- Node.js 22 или новее.
- Claude Code CLI, вход по подписке. Проверка перед запуском:

  ```bash
  claude auth status
  ```

  Ожидается `"loggedIn": true`, `"authMethod": "oauth_token"`, `"apiProvider": "firstParty"`. Переменной `ANTHROPIC_API_KEY` в окружении быть не должно: с ней CLI тарифицируется по API, а не по подписке. Флаг `--bare` не используется.
- Доступ в интернет к источникам из `editorial/sources.json` и к бесплатным каналам интереса (Hacker News, Bluesky, Google News RSS). За корпоративным прокси запускайте с `NODE_OPTIONS=--use-env-proxy`: иначе `fetch` в Node не читает `HTTPS_PROXY`.

## Что делает запуск

1. **Источники.** `editorial/sources.json`: ленты RSS/Atom, каждая с пометкой, откуда она взята (прежний отбор или новый кандидат). Недоступная лента попадает в отчёт запуска и не останавливает остальные.
2. **Отбор повода.** Запись проходит, только если в заголовке или аннотации есть и термин про ИИ-поиск, и термин про рестораны/отели, а дата не старше `--lookback-days` (по умолчанию 14). Официальный источник выше отраслевой прессы, свежее выше старого. Оценка печатается в лог.
3. **Подтверждение события.** Страница первоисточника скачивается, превращается в текст и сохраняется в пакет (`page.txt`). Поводом считаются только предложения, которые дословно есть на странице и упоминают обе стороны. Код ответа 200 или совпадение слов в заголовке подтверждением не считаются. Дата берётся из разметки страницы, при её отсутствии — из ленты, с пометкой.
4. **Признаки интереса.** Отдельно от подтверждения: число результатов в Hacker News, Bluesky и число изданий в Google News по запросу из заголовка. Это не доказательство события, а повод упомянуть интерес с числами или промолчать.
5. **Защита от повторов.** `editorial/drafts/ledger.json` хранит каждый взятый повод: ключ первоисточника, слова заголовка, термины, дату. Повод считается тем же, если совпал первоисточник, или заголовок на 50 % и больше состоит из тех же слов в пределах 45 дней, или то же издание в пределах трёх дней называет те же два и более термина. Хеш текста — версия материала, а не защита от повтора темы.
6. **Текст.** `claude -p` без инструментов, без сохранения сессии, с ограничением бюджета, структурированный ответ по схеме. Бриф — `editorial/PROMPT.md`.
7. **Проверка текста** до сохранения: каждое фактическое утверждение ссылается на id доказательства; английская версия ссылается только на те же id, что русская; в английской нет чисел, которых нет в русской или в доказательствах; в русской нет чисел, которых нет в доказательствах; ссылки только на первоисточник; нет фраз о собственных клиентах, замерах и экспериментах. Ошибка — один повтор с перечнем ошибок, затем отказ с сохранённым выводом модели.
8. **Пакет.** `editorial/drafts/<дата>-<slug>/`: `article.ru.md`, `article.en.md`, `telegram.ru.md`, `hook.json`, `page.txt`, `writer-output.json`, `verification.md`, `manifest.json`. Заголовок статьи — первая строка файла, заголовок для поиска (13–43 знака) и источники в формате Lab (`hook.json` → `labSources`) готовы для конвертера Control Room. Все отметки времени — Asia/Makassar (UTC+8) и UTC.

Коды выхода: `0` — черновик сохранён; `3` — нового повода нет, все подходящие уже в реестре; `2` — отказ (источники не прочитаны, повод не подтверждён, текст не прошёл проверку), причина в `editorial/drafts/<дата>-refusal*/refusal.md`; `1` — сбой самого запуска. Каждый запуск дописывает строку в `editorial/drafts/runs.jsonl`.

## Флаги

| Флаг | Что делает |
|---|---|
| `--lookback-days N` | Окно свежести, по умолчанию 14 |
| `--dry-run` | Остановиться после подтверждения повода и напечатать пакет доказательств; модель не вызывается |
| `--allow-repeat` | Переписать уже взятый повод; новая версия добавляется в `manifest.json` и реестр |
| `--only-source id` | Читать одну ленту |
| `--candidate-url url` | Пропустить ленты и проверить одну страницу |
| `--budget-usd N` | Потолок для `claude -p --max-budget-usd`, по умолчанию 1 |
| `--model name` | Модель для `claude -p`; без флага — модель по умолчанию CLI |
| `--no-interest` | Не собирать признаки интереса |
| `--fixtures map.json`, `--writer fixture` | Только для тестов: локальные файлы вместо сети и заглушка вместо модели. Такой пакет помечен как тестовые данные |

## Первый запуск на вашей машине

Контейнер сессии, в котором запуск собирался 11.10.2026, не резолвит внешние хосты, поэтому ни одна лента из `sources.json` ещё не читалась (`feedVerified: null`). Первый запуск с вашей машины покажет по каждому источнику `ok`, `unreachable` или `unreadable`. Для `unreachable`/`unreadable` у источника с `feedGuess: true` откройте его сайт, найдите настоящий адрес RSS (обычно `/feed`, `/rss`, `/rss.xml` или ссылка `application/rss+xml` в коде страницы) и поправьте `feed` в `sources.json`. Источник можно выключить строкой `"enabled": false`.

Если первый запуск закончился отказом «нет подходящего повода», это нормальный результат: статья пишется только по поводу, который прошёл проверку.

## Что в git, что нет

Скрипты (`scripts/editorial/`), бриф, список источников, этот файл и тесты (`tests/unit/editorialRun.test.ts`) — в репозитории. Папка `editorial/drafts/` вместе с реестром и журналом запусков — исключена из git: черновики, пока их не одобрил владелец, в репозиторий не попадают.

## Чего запуск не делает

- Не публикует и не заменяет существующий путь: одобренная статья попадает в Lab через Aether и Control Room (репозитории `Aether-Medium` и `selena-OS`), которые открывают PR с парой файлов `data/lab/<раздел>/<slug>.<ru|en>.json` по правилам `docs/22-selena-lab-publishing.md`. Папка `editorial/drafts/` — временное место для первого результата; пакет из неё передаётся в Aether, а не мимо него.
- Не ходит в платные сервисы (Oxylabs, Ahrefs, DataForSEO) и не использует API-ключ.
- Не меняет расписания и настройки сервисов.
