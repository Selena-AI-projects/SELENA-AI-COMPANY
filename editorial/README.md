# Редакционный прогон Selena Lab (локально)

Повторяемый локальный прогон: **проверяемый повод → редакционный замысел →
статья RU → английская адаптация → анонс Telegram → сохранённый черновик.**
Ничего не публикует: черновик лежит в `editorial/drafts/` (вне git) и ждёт
согласования владельцем; публикация — по `docs/22-selena-lab-publishing.md`
(файлы `data/lab/<раздел>/<slug>.<ru|en>.json`, одним pull request).

Решение владельца от 11.10.2026: локальная реализация, без commit/push/deploy,
без изменения расписаний, сервисов и оплаты. Snapshot, worker, locks и кнопки
запуска не затрагиваются.

## Состав

```
editorial/
  README.md            — этот документ
  sources.json         — белый список первичных источников (+ одно добавление, ждёт подтверждения)
  triggers/*.json      — проверяемые поводы: url, дословные цитаты, дата на странице, угол
  triggers/examples/   — тестовые поводы для демонстрации отказов (помечены)
  registry.json        — журнал выпущенных тем (дедупликация по key и url)
  lib.mjs              — чистые функции: цитаты, дедупликация, сверка утверждений, время Asia/Makassar
  pipeline.mjs         — оркестрация прогона
  validate-lab.ts      — проверка черновика парсером Лаборатории
  drafts/              — черновики (git-ignored): <ГГГГ-ММ-ДД>-<slug>/
tests/unit/editorialPipeline.test.ts — тесты чистых функций (6)
```

## Запуск

```bash
node editorial/pipeline.mjs --trigger editorial/triggers/anthropic-crawlers-robots.json
# повтор с тем же поводом → ALREADY_COVERED, новой статьи нет
# проверки чистых функций:
node --import tsx --test tests/unit/editorialPipeline.test.ts
```

Требования: Node 22, `npm ci`, установленный Claude Code CLI с входом по
подписке (`claude auth status` → `authMethod: oauth_token`). Если в окружении
задан `ANTHROPIC_API_KEY`, прогон отказывается: платные вызовы API запрещены.

## Как устроен прогон

1. **Дедупликация** до любой сети: совпал `key` или `url` повода в `registry.json` → `ALREADY_COVERED`, выход 0, ничего не создаётся. Хеш текста источника хранится как версия, не как признак новизны.
2. **Белый список и способ оплаты**: адрес повода должен быть в `sources.json`; `claude auth status` должен показывать подписку.
3. **Подтверждение повода** — `curl` к адресу источника (прокси и CA окружения), затем каждая цитата из повода ищется **дословно** в тексте страницы (после нормализации кавычек и пробелов) + дата на странице. HTTP 200 и совпадение ключевых слов подтверждением не считаются. Что не найдено — `REFUSAL.md` с перечнем, выход 2, журнал не меняется.
   Разделение: *подтверждение события* — цитаты и дата (`trigger-evidence.json`); *сигналы интереса* — поле `interestSignals` повода (в этом прогоне не измерялись); *наш вывод* — элементы с меткой `ИНТЕРПРЕТИРОВАНО` / `INTERPRETED`.
4. **Модель** — `claude -p … --output-format json --json-schema … --tools "" --no-session-persistence --max-turns 1`: только структурированный ответ, без инструментов и сессий. Четыре вызова: замысел (каждое утверждение с номером цитаты), статья RU, адаптация EN по русской версии, анонс Telegram. Модель может вернуть `refusalReason` — тогда отказ.
5. **Проверки** (любая неудача — отказ, черновик помечен `REFUSAL.md`):
   - формат RU и EN — `lib/lab/files.ts` как при публикации;
   - `editorial/lib.mjs#checkClaims`: источники и `cite` только из белого списка и повод среди них; метки на языке версии; внутренние ссылки на страницы своего языка; числа EN ⊆ RU; одинаковые slug/section/источники; запретные формулировки (клиенты/кейсы, гарантии, «мы измерили»);
   - анонс: ссылка на материал и на первоисточник, ≤ 700 знаков, без гарантий.
6. **Сохранение**: `trigger-evidence.json`, `source-text.txt`, `brief.json`, `<slug>.ru.json`, `<slug>.en.json`, `telegram.ru.md`, `checks.json`, `run.json` (время Asia/Makassar, модели, токены, `total_cost_usd` из ответа CLI), `manifest.sha256`; запись в `registry.json`.

### Что нужно знать владельцу (ограничения)

- **Сетевая политика среды прогона** закрывает ранее выбранные источники
  (developers.google.com, help.openai.com, schema.org, arxiv.org — `CONNECT 403`).
  Поэтому для полного прогона использован официальный документ Anthropic
  (support.claude.com) — добавлен в `sources.json` с пометкой `addedOn`/`addedWhy`
  и **ждёт подтверждения владельца**. На машине с открытой сетью те же поводы по
  Google/OpenAI работают без изменений кода.
- Черновик — **не согласованный текст**: по `docs/22` русская версия сначала
  согласуется владельцем, английская готовится по согласованной русской. Здесь EN
  сделан по несогласованной RU — это черновик адаптации, не финальная версия.
- Сигналы интереса (поиск, трафик, вопросы клиентов) не измерялись: из среды нет
  доступа к Search Console и аналитике. Поле `interestSignals` повода заполняется
  владельцем или отдельным замером.
- Публикация в Telegram и на сайт не выполнялась и конвейером не предусмотрена.
- Тестовые данные: `tests/unit/editorialPipeline.test.ts` — синтетика;
  `triggers/examples/` — поводы для демонстрации отказов, в них есть
  придуманная цитата (так и помечено).
